# Airline Passenger Satisfaction Analysis

Datengetriebene Analyse zur Passagierzufriedenheit im Luftverkehr.  
Das Projekt basiert auf dem Notebook `Airline_Passenger_Satisfaction_Analysis.ipynb`.

Autor:innen
- Hasan Hüseyin Demirci
- Andreas Hubertus
- Sebastian Rein
- Vitalii Solonychnyi

Beschreibung
- Ziel: Untersuchung, welche Faktoren die Gesamtzufriedenheit von Flugpassagieren beeinflussen und wie einzelne Bewertungsfaktoren miteinander korrelieren.
- Methodik: Explorative Datenanalyse im CRISP‑DM-Framework mit Python (Pandas, Matplotlib, Seaborn, ggf. Plotly).


Daten-Ursprung: 
Kaggle — "Airline Passenger Satisfaction"  
  https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction/data  


Dateien
- Airline_Passenger_Satisfaction_Analysis.ipynb — Haupt-Notebook mit Analyse, Visualisierungen und Fazit.
